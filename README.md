# gif-creator
gif creation helper made for the CookieRun Wiki, the program is still a work in progress and will continue development

# Requirements
This program requires the following to be installed on your computer:

[Python](https://www.python.org/downloads/)
[Imagemagick](https://imagemagick.org/download/)
[Gifsicle](https://www.lcdf.org/gifsicle/)
